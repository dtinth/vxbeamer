Sign in by pairing, and only by pairing: paste the link the backend's `/pair` page shows, or scan its QR code with the qr.spacet.me scanner. Works where an in-browser sign-in cannot, such as an iOS home-screen app, where Google shows you as logged out.

The link names the backend, so the Backend URL setting is gone. The old sign-in buttons ("Sign in with OIDC", "Log in with another browser") and the desktop sign-in code page are removed along with the in-browser OIDC callback.
